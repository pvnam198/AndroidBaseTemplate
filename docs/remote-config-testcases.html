Remote Config – Thông số & Test case

Mở file này trong trình duyệt. Kết quả Pass/Fail tự lưu trong trình duyệt (không ghi vào CSV).

Cách test
  1. Dùng bản DEBUG. Vào Settings → Debug config, đặt giá trị từng key rồi bấm Lưu override.
  2. Firebase chỉ có một key ad_config (cả khối JSON). Ở Debug config có thể dán cả khối vào dòng ad_config, hoặc sửa riêng từng dòng (tên trong settings, hoặc key vị trí: một số = enable, hay JSON {"enable":3,"wait_time":5000,"inter":{"name1":"INTER_SPLASH","id1":"…"}}). Thời gian tính bằng ms. Cấu hình ở Splash (ads_enable, ads_splash, native_splash, on_resume, splash_fallback) → đóng hẳn và mở lại app.
  3. Xem lại Language/Onboarding: Settings → Reset onboarding rồi mở lại app.
  4. Xoá hết override để về giá trị Firebase/default.
Mọi key đều có thể override ở màn Debug config. Nguồn: key ad_config, đọc ở core/config/RemoteConfig.kt và core/config/PlacementConfig.kt. Chi tiết: docs/remote-config.md.
